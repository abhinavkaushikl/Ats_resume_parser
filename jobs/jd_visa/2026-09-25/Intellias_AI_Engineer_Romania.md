## Job description

Intellias helps retailers deliver consistent, omnichannel experiences through technology. We are looking for a hands-on **AI Engineer** to lead the technical design and delivery of enterprise AI agents and Model Context Protocol (MCP)-based integrations, building scalable solutions that drive performance and customer value.

The team will develop **MCP services for local business applications** and AI agents that consume both these local MCPs and services provided by a global platform team. The Senior AI Engineer will own solution design, support use-case discovery, provide technical leadership to the engineering team, and stay directly involved in implementation.

**Required skills**

* Strong **Python** development skills.
* Backend or integration engineering experience.
* REST API development and integration.
* Microsoft Azure experience.
* Experience with LLM applications, tool/function calling or AI agents.
* OAuth 2.0 / Microsoft Entra ID or similar identity technologies.
* SQL and JSON.
* Git and CI/CD.
* Understanding of software engineering practices, testing and production support.
* English communication skills.

**Strong advantage**

* **Model Context Protocol (MCP)** experience.
* Azure AI Foundry / Azure OpenAI.
* Copilot Studio.
* Semantic Kernel, LangGraph or other agent frameworks.
* Azure Functions / API Management.
* Power Automate.
* Experience integrating AI solutions with enterprise applications.

**Responsibilities:**

* Develop **MCP servers/services for local applications**.
* Expose application capabilities, data and business operations to AI agents through secure MCP interfaces.
* Integrate MCP services with existing REST APIs, databases and enterprise applications.
* Develop AI agents consuming both **local and global MCPs**.
* Implement agent instructions, tool calling, workflow logic and guardrails.
* Implement authentication, authorization and secure access to enterprise systems.
* Build reusable integration components and MCP tools.
* Perform end-to-end testing of agents and MCP integrations.
* Troubleshoot agent/tool interactions and integration failures.
* Monitor agent performance, reliability, latency and cost.
* Implement automated tests and CI/CD.
* Work closely with the Senior AI Engineer, global AI/platform teams and application owners.
