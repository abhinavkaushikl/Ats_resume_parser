## Job description

Stanowisko
Obecnie dla naszego klienta z branży farmaceutycznej poszukujemy kandydata/kandydatki na stanowisko (K / M) Machine Learning Engineera.

Oferowane wynagrodzenie
Wynagrodzenie: od 1000 do 1250 PLN netto/dzień, w zależności od posiadanego doświadczenia i kompetencji.

Sprawdzisz się w tej roli, jeżeli:

- Posiadasz minimum 5 lat doświadczenia na stanowisku Machine Learning Engineer lub pokrewnym

- Posiadasz wykształcenie magisterskie lub doktoranckie w obszarze Informatyki, Sztucznej Inteligencji, Machine Learning lub pokrewnym

- Masz doświadczenie z narzędziami do monitorowania modeli i obserwowalności systemów, takimi jak Prometheus, Grafana czy Evidently AI

- Bardzo dobrze programujesz w języku Python oraz znasz jego ekosystem wykorzystywany w projektach Data Science

- Posiadasz doświadczenie w projektowaniu, wdrażaniu oraz utrzymaniu produkcyjnych systemów Machine Learning

- Znasz AWS SageMaker i wykorzystywałeś/-aś go do trenowania oraz wdrażania modeli

- Masz praktyczne doświadczenie z MLOps, w szczególności z MLflow oraz GitLab CI/CD,potrafisz projektować skalowalne architektury danych i pipeline'y ML

- Znasz przynajmniej jeden framework Deep Learning (TensorFlow lub PyTorch)

- Potrafisz przekładać wymagania biznesowe na rozwiązania techniczne

- Dobrze odnajdujesz się w roli mentora i potrafisz wspierać rozwój innych członków zespołu

- Swobodnie komunikujesz się w języku angielskim (min.B2)

Zadania, które na Ciebie czekają:

- Rozwój i projektowanie architektury produkcyjnego systemu rekomendacyjnego wykorzystywanego globalnie

- Rozwijanie i optymalizacja procesów MLOps, w tym pipeline'ów CI/CD w GitLab oraz zarządzania eksperymentami z wykorzystaniem MLflow

- Wdrażanie modeli Machine Learning do środowiska produkcyjnego z wykorzystaniem AWS SageMaker

- Współpraca z Data Scientistami przy przygotowywaniu skalowalnych i produkcyjnych rozwiązań ML

- Mentoring oraz wsparcie techniczne dla zespołów Data Science, Data Engineering i MLOps

- Tworzenie wysokiej jakości kodu w Pythonie dla infrastruktury danych i systemów Machine Learning

- Współpraca z Product Managerami oraz interesariuszami biznesowymi w celu przekładania potrzeb biznesowych na rozwiązania techniczne

- Identyfikowanie i wdrażanie nowych technologii oraz najlepszych praktyk w obszarze Machine Learning i MLOps
