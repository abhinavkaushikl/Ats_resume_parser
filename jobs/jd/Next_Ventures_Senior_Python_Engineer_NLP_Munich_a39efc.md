## Job description

Role Overview

We are seeking an experienced AI/ML Python Engineer to build and scale intelligent applications powered by machine learning and large language models. You will design and develop Python-based services, data pipelines, and AI-powered features that transform unstructured data into actionable insights.

Working closely with product, data, and platform teams, you will integrate LLMs, NLP models, and AI workflows into production systems while contributing to the evolution of our cloud-native AI platform.

This role is ideal for an engineer who combines strong software engineering fundamentals with practical experience building and deploying AI/ML solutions.

Key Responsibilities

- Design, develop, and maintain Python applications and services that power AI/ML products.

- Build and optimize data pipelines for processing structured and unstructured datasets at scale.

- Integrate, deploy, and evaluate Large Language Models (LLMs) and NLP solutions within production environments.

- Develop APIs, microservices, and backend systems that expose AI capabilities to internal and external applications.

- Collaborate with product managers, data scientists, and platform engineers to translate business requirements into scalable technical solutions.

- Implement prompt engineering, model orchestration, retrieval-augmented generation (RAG), and AI workflow automation where appropriate.

- Contribute to model monitoring, evaluation, testing, and continuous improvement processes.

- Write high-quality, maintainable, and well-tested Python code following engineering best practices.

- Support deployment and operation of AI services within AWS-based environments.

- Participate in architecture discussions and help drive technical decisions for AI-enabled products.

Required Qualifications

- Bachelor's or Master's degree in Computer Science, Data Science, Engineering, or a related field.

- 4+ years of professional software engineering experience, with a strong focus on Python development.

- Proven experience building production-grade backend applications and APIs using Python.

- Hands-on experience working with machine learning or AI-powered applications.

- Strong understanding of software engineering best practices, including testing, version control, code reviews, and CI/CD.

- Experience with relational and/or NoSQL databases.

- Familiarity with Linux, Docker, Git, and cloud-native development workflows.

- Experience working within Agile software development teams.
