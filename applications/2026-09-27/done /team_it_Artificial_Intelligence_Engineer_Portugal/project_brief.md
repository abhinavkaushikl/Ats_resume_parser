## On the resume

- Built an agentic RAG assistant that answered questions over banking policy and product documents, combining a vector database, LangGraph tool routing and Claude through AWS Bedrock.
- Evaluated answer quality with LLM evaluators on a labelled question set, traced each agent step, and served the assistant as a FastAPI service in Docker on Kubernetes.

**Technologies:** LangGraph, LangChain, AWS Bedrock, pgvector, Hugging Face, FastAPI, Docker, Kubernetes
