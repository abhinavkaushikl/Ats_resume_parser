## On the resume

- Built a multi-agent assistant in LangGraph for insurance claims triage, where a supervisor agent routed work to retrieval, policy-check and summary agents exposed as MCP tools with shared memory.
- Evaluated agent answers with LLM evaluators and trace reviews on a labelled claims set, and served the system through FastAPI in Docker with pgvector retrieval over policy documents.

**Technologies:** LangGraph, LangChain, MCP, Hugging Face, PyTorch, pgvector, FastAPI, Docker
