## On the resume

- Built an event-detection model for football tracking data, classifying passes, shots and set pieces from player and ball trajectories with an LSTM in PyTorch and XGBoost baselines.
- Evaluated per-event precision and recall with error analysis on hand-annotated matches, and served batched inference through FastAPI in Docker with MLflow experiment tracking.

**Technologies:** PyTorch, LSTM, XGBoost, Python, MLflow, FastAPI, Docker
