# Project prep - Freight Price Estimation Model

Added for: Machine Learning Engineer at sennder (Amsterdam)
Apply: https://nl.linkedin.com/jobs/view/machine-learning-engineer-at-sennder-4453121690
Company profile: sennder is a European digital freight forwarder running road logistics on one platform that connects shippers with carriers.

## On the resume

- Built a price estimation and capacity forecasting model for road freight lanes, combining LightGBM regression on lane, distance and seasonality features with Holt-Winters baselines.
- Validated it with backtesting and hypothesis tests against rule-based pricing, served estimates through FastAPI with MLflow tracking, and shared results in a Streamlit dashboard.

**Technologies:** Python, SQL, LightGBM, Streamlit, Jupyter, FastAPI, MLflow, Pandas
