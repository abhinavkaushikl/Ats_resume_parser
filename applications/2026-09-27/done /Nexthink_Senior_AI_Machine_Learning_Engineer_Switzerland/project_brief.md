# Project prep - IT Issue Triage Agent

Added for: Senior AI Machine Learning Engineer at Nexthink (Switzerland)
Apply: https://jobs.smartrecruiters.com/Nexthink/744000130034719-senior-ai-machine-learning-engineer
Company profile: Nexthink makes digital employee experience management software that lets IT teams see, diagnose and fix issues across applications, devices and networks before employees notice them.

## On the resume

- Built a multi-agent assistant that inspects endpoint and application logs, retrieves past fixes with RAG and proposes remediation steps for employee IT issues before tickets pile up.
- Evaluated answers with automated LLM evaluations and regression metrics in a CI pipeline, versioned prompt and embedding configs in MLflow, and deployed the service on AWS with Docker.

**Technologies:** Python, LangChain, PyTorch, RAG, MLflow, AWS, Docker, Jenkins
