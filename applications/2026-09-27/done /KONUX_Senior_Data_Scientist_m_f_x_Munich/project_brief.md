# Project prep - Vibration Sensor Anomaly Detection

Added for: Senior Data Scientist at KONUX (Munich)
Apply: https://job-boards.greenhouse.io/konux/jobs/7805858003
Company profile: KONUX builds AI and IIoT solutions that help railway operators monitor infrastructure and plan maintenance from sensor data.

## On the resume

- Built an anomaly detection and failure-risk model for industrial vibration sensor data, extracting rolling statistical and frequency features with Pandas and scoring them with Isolation Forest and LightGBM.
- Evaluated detections against labelled maintenance events with backtesting, packaged the pipeline with unit tests and CI/CD on Databricks, and tracked and monitored models in MLflow.

**Technologies:** Python, Pandas, PySpark, Databricks, Isolation Forest, LightGBM, MLflow, Git
