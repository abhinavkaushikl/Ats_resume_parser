# Project prep - Prepaid Churn and Fraud Scoring

Added for: Senior Machine Learning Engineer at Rebtel (Stockholm)
Apply: https://rebtel.teamtailor.com/jobs/7805704-senior-machine-learning-engineer
Company profile: Rebtel is a Stockholm-based international calling and mobile top-up app that helps diaspora communities stay connected with family and friends across borders.

## On the resume

- Built churn prediction and top-up fraud scoring for a prepaid telecom user base, combining engineered behavioural features with LightGBM and Isolation Forest to flag risky accounts.
- Validated models on time-based splits with drift monitoring and scheduled retraining in Airflow, tracked runs in MLflow, and served scores through FastAPI on Kubernetes.

**Technologies:** Python, LightGBM, Isolation Forest, MLflow, Airflow, Kubernetes, FastAPI, SQL
