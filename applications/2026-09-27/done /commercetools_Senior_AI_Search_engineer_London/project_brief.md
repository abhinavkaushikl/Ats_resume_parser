# Project prep - Hybrid Product Search Engine

Added for: Senior AI Search engineer at commercetools (London)
Apply: https://job-boards.greenhouse.io/commercetools/jobs/8003157003
Company profile: commercetools provides an API-first, headless commerce platform that enterprise brands use to build online shopping and product discovery.

## On the resume

- Built hybrid product search for large e-commerce catalogs, combining keyword retrieval in Elasticsearch with embedding-based vector search and a fine-tuned cross-encoder re-ranker for natural-language queries.
- Measured relevance with NDCG and recall on labelled query sets alongside per-query latency, and served it as a multi-tenant REST API with FastAPI on Kubernetes.

**Technologies:** Elasticsearch, Apache Solr, Vector DB, Embeddings, Cross-Encoder, FastAPI, Kubernetes, Python
