# Project prep - Network Reliability Insights Assistant

Added for: Senior Data Science Engineer at Verizon (Dublin)
Apply: https://mycareer.verizon.com/jobs/r-1100318/senior-data-science-engineer/
Company profile: Verizon is a telecommunications company running large mobile and fixed networks for consumers and businesses.

## On the resume

- Built an agentic analytics assistant for telecom network reliability that queried KPI and alarm data in SQL, flagged anomalies with Isolation Forest and explained likely causes through an LLM.
- Validated anomaly flags against labelled incidents, tracked experiments in MLflow, stored results in Google BigQuery and surfaced them through Looker dashboards and a FastAPI service.

**Technologies:** Python, SQL, Google BigQuery, Looker, LangGraph, Isolation Forest, MLflow, FastAPI
