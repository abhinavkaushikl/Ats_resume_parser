# Project prep - Match Event Detection Pipeline

Added for: Senior Machine Learning Engineer at veo (Copenhagen)
Apply: https://jobs.lever.co/veo/49afc19d-6f36-4832-8f2f-71d0d9a568ad
Company profile: Veo builds AI-powered sports cameras and analysis software that track every player and the ball, giving clubs and youth players match footage, data and analytics.

## On the resume

- Built an event detection model for football tracking data, training a PyTorch LSTM on player and ball position sequences to flag key match moments such as shots and runs.
- Evaluated per-event precision and recall with error analysis on missed moments, and served the model through a FastAPI inference pipeline in Docker with experiments tracked in MLflow.

**Technologies:** PyTorch, LSTM, Python, MLflow, FastAPI, Docker, Kubernetes
