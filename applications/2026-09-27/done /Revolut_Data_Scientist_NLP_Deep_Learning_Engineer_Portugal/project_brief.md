# Project prep - Banking Support Copilot

Added for: Data Scientist (NLP Deep Learning Engineer) at Revolut (Porto)
Apply: https://www.revolut.com/en-IN/careers/position/data-scientist-nlp-deep-learning-engineer-7fdeec15-cd49-4ca9-b509-ae6ca2613cd5/
Company profile: Revolut is a global financial app offering spending, saving, investing and exchange products to retail customers.

## On the resume

- Built a customer support copilot for digital banking that classifies incoming chats with a fine-tuned BERT model and drafts grounded replies with an LLM using RAG over help articles.
- Evaluated intent accuracy and answer quality with LLM evaluators and human-labelled samples, then served both models through FastAPI in Docker with MLflow tracking and tracing.

**Technologies:** Python, PyTorch, Hugging Face Transformers, BERT, LangGraph, FastAPI, Docker, MLflow
