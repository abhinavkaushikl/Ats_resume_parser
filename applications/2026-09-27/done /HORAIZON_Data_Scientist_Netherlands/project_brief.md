# Project prep - Microbiome Profile Classification Service

Added for: Data Scientist at HORAIZON (Delft)
Apply: https://nl.linkedin.com/jobs/view/data-scientist-at-horaizon-4472043744

## On the resume

- Built a pipeline that classifies health outcomes from microbiome abundance profiles, combining feature filtering with scikit-learn and PyTorch models suited to sparse, high-dimensional biological data.
- Evaluated models with cross-validation and clear visual reports for non-technical readers, then served predictions through a REST API built with Django REST Framework in Docker.

**Technologies:** Python, PyTorch, scikit-learn, Django REST Framework, Pandas, Matplotlib, Docker
