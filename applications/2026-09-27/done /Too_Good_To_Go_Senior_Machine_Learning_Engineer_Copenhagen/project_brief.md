# Project prep - Marketing Personalization Recommender

Added for: Senior Machine Learning Engineer at Too Good To Go (Copenhagen)
Apply: https://dk.linkedin.com/jobs/view/senior-machine-learning-engineer-at-too-good-to-go-4466189279
Company profile: Too Good To Go runs a marketplace app that connects consumers with food businesses selling surplus food, with the mission of reducing food waste.

## On the resume

- Built a personalized recommendation model for marketplace marketing campaigns, ranking items for each user with LightGBM on behavioural features and PyTorch embeddings of users and items.
- Evaluated ranking quality offline, checked uplift with statistical hypothesis tests on A/B experiments, and scheduled training and batch scoring with Metaflow, Airflow and Docker.

**Technologies:** Python, SQL, PyTorch, Scikit-learn, LightGBM, Metaflow, Airflow, Docker
