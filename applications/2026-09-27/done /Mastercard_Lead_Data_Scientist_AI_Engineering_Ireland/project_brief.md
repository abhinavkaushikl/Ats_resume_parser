# Project prep - Transaction Embedding Propensity Models

Added for: Lead Data Scientist, AI Engineering at Mastercard (Dublin)
Apply: https://careers.mastercard.com/us/en/job/R-277460/Lead-Data-Scientist-AI-Engineering
Company profile: Mastercard runs a global payments network, and its AI Centre of Excellence builds machine learning and foundation-model capabilities on large-scale transaction data.

## On the resume

- Built customer propensity and churn models on card transaction sequences, learning transformer-based embeddings of spending behaviour in PyTorch and feeding them into LightGBM as reusable features.
- Benchmarked embedding features against hand-crafted baselines using time-based splits and AUC comparisons, tracked runs in MLflow and ran batch scoring on Databricks with Spark.

**Technologies:** Python, PyTorch, LightGBM, Scikit-learn, Databricks, Spark, MLflow, SQL
