# Project prep - Delivery Time Prediction Service

Added for: Senior Machine Learning Engineer at Picnic Technologies (Amsterdam)
Apply: https://nl.linkedin.com/jobs/view/senior-machine-learning-engineer-at-picnic-technologies-4284413550
Company profile: Picnic is an app-only online grocery service with its own electric delivery fleet and warehouses, using machine learning across forecasting, delivery and recommendations.

## On the resume

- Built a model predicting drop-off times for last-mile grocery delivery, training LightGBM on route, order and time-of-day features prepared with SQL and pandas.
- Evaluated the model with time-based backtesting against a historical-average baseline, tracked experiments in MLflow and served predictions through FastAPI on Kubernetes with CI checks and drift monitoring.

**Technologies:** Python, SQL, LightGBM, MLflow, FastAPI, Docker, Kubernetes, Jenkins
