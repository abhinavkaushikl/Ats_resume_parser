# Project prep - Hybrid Product Search Engine

Added for: Senior AI Search engineer at commercetools (Berlin)
Apply: https://job-boards.greenhouse.io/commercetools/jobs/8003149003
Company profile: commercetools builds a headless, API-first commerce platform that large brands use to run product discovery and online shopping at scale.

## On the resume

- Built a hybrid product search service for ecommerce catalogs, combining Elasticsearch keyword matching with vector retrieval and query understanding for full-sentence shopper queries.
- Evaluated relevance with offline judgment sets and NDCG across keyword and hybrid modes, re-ranked results with a fine-tuned cross-encoder, and served the API through FastAPI on Kubernetes.

**Technologies:** Elasticsearch, Hybrid Search, Vector Search, Cross-Encoder, SBERT, FastAPI, Kubernetes, Python
