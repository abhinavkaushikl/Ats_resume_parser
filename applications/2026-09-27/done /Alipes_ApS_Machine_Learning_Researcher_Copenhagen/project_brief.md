# Project prep - Equity Return Forecasting Pipeline

Added for: Machine Learning Researcher at Alipes (Copenhagen)
Apply: https://careers.alipes.dk/jobs/4881094-machine-learning-researcher
Company profile: Alipes is a Copenhagen trading firm that automates decisions in financial and energy markets with statistical and machine learning models.

## On the resume

- Built a forecasting pipeline for equity price returns, generating lagged market and news-sentiment features and comparing LSTM, XGBoost and LightGBM models against statistical baselines.
- Benchmarked the models with walk-forward backtesting, tracked every run and dataset version in MLflow, and monitored live prediction drift against realised returns.

**Technologies:** Python, PyTorch, XGBoost, LightGBM, Pandas, NumPy, LSTM, MLflow
