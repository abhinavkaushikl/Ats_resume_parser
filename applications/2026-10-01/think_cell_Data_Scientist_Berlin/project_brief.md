# Project prep - Product Usage Churn Scoring Engine

Added for: Data Scientist at think-cell Software (Berlin)
Company profile: think-cell is a Berlin software company, founded in 2002, whose tools integrate with Microsoft Office so professionals can build presentations, charts and diagrams quickly.

## On the resume

- Built a churn and renewal risk scoring engine for a desktop software product, engineering behavioural usage features from licence and telemetry data with LightGBM and logistic regression.
- Validated it with time-based splits and leakage checks, calibrated the scores with uncertainty bands, and operationalized recurring scoring in Airflow with MLflow tracking and drift monitoring for commercial teams.

**Technologies:** SQL, Python, pandas, scikit-learn, LightGBM, Airflow, MLflow, Power BI
